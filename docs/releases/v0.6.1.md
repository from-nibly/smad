# SMAD v0.6.1

## YAML frontmatter rendering

- Render leading YAML frontmatter in a compact, initially collapsed **Document metadata · YAML** section instead of interpreting its delimiters as rules or oversized headings.
- Preserve YAML formatting, syntax highlighting, selectable text, and the original metadata and delimiters when copying across the document.
- Source-line highlights targeting any part of the frontmatter highlight and automatically expand the entire metadata section. Body highlights retain their original source coordinates, including CRLF files.
- Keep incomplete and nonleading metadata-like blocks as ordinary Markdown, preserving later horizontal rules and setext headings.
- Ignore Mermaid-looking examples inside frontmatter when preparing diagrams.

No new dependencies, protocol changes or persistence migrations. Native Markdown remains native GTK.
