# SMAD v0.5.1

Code and comparison attention highlights now use full-width amber backgrounds instead of underlines. Short and empty source lines receive the same visible emphasis across the text viewport.

- Native GTK drawing beneath the text fills empty paragraphs without inserting characters or changing copied source.
- Syntax colors retain contrast in light and dark themes; normal text selection and the caret remain above the highlight.
- Highlighted comparison rows use amber backgrounds while the separate red/green +/− gutter markers preserve addition/deletion meaning.
- Existing ranges, previous/next navigation, clearing, live reloads and source coordinates remain unchanged.
- Pixel regression checks cover blank highlighted rows at the viewport's far edge in both themes, alongside the native integration suite.

This patch changes native code/comparison views, not Markdown's precise source-span mapping. Markdown's existing unmapped-syntax and blank-code-line warnings still apply. No protocol, persistence or service-ownership migration is required.
