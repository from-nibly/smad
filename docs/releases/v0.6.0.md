# SMAD v0.6.0

## Broader native syntax highlighting

- Expand the bundled syntax set from 75 to **252 definitions**, with **133 executable coverage cases**, across native code views, full-file comparisons and Markdown fences.
- Add CUE, Nix, Terraform/HCL and broad programming, infrastructure, shell, data, build, shader and markup coverage. TypeScript/TSX now use real grammars rather than the JavaScript fallback.
- Recognize whole filenames, compound suffixes and supported first-line signatures, including Dockerfile/Containerfile, CMakeLists.txt, Cargo.lock, go.mod, .env.local, BUILD.bazel and .html.j2.
- Bundle a pinned upstream collection and attributed community supplements, with clearly labeled basic lexical additions. Link and validate grammars at build time; no runtime downloads or new system Oniguruma dependency.
- Preserve source text, copied text, original coordinates, snapshots, syntax limits, selection and full-width attention highlights. Unknown/oversize sources remain plain text; parser failures fall back losslessly.

The definition count includes file formats and helper grammars, not 252 distinct languages. See [coverage and accuracy limits](../syntax-highlighting.md) and the [generated catalog](../syntax-catalog.md).

## Project-tab snap-back fixes

- Record tab/sidebar selection immediately during the GTK signal, deferring only persistence and widget updates. Background renders can no longer restore the old selection in that gap, and deferred work no longer replays stale selection keys.
- Ignore redundant HerdR focus notifications for the same identity, including subscription reconnects, so they do not override manual browsing. Real focus changes, closures, label refresh and explicit `--once` synchronization retain their behavior.

Both paths have regression tests, including private-socket testing against the prior release and an isolated GTK test. The original intermittent text-drag trigger was not confirmed; these fixes address the independently reproduced races.

## Compatibility

No protocol, URI, persistence, project identity or service-name migration. Legacy aliases remain supported. Native documents remain native GTK; WebKit remains lazy for web reviews. Lifecycle synchronization still never starts or raises SMAD.
